# Nava Nirmana website

A responsive, static multi-page company website based on the company profile and the supplied website blueprint.

## Preview

Open `index.html` in a browser. Typography uses system fonts and does not load fonts from a third-party link. The illustrative Unsplash photography needs an internet connection and does not represent Nava Nirmana clients or projects. Replace it with approved company imagery and confirm image licensing before publishing.

## Pages

- `intro.html` - an opening for the website
- `index.html` — Home and company positioning
- `about.html` — Story, vision, mission and philosophy
- `services.html` — Service overview
- `management.html` — Hospitality management and operations
- `development.html` — Property development and transformation
- `commercial-growth.html` — Revenue, distribution and sales strategy
- `insights.html` — Editorial perspectives
- `contact.html` — Contact details and inquiry form

## Interactions

- Responsive navigation with service links
- Interactive service tabs on the homepage
- Expandable insight articles
- Inquiry form that drafts an email for the visitor to review and send
- WhatsApp and email contact links
- Subtle scroll reveal animations and a reading progress indicator
- Reduced-motion support for visitors who prefer fewer animations
- Locally stored company logo and system fonts; no remote font download

The profile's financial illustrations are estimates, so the website does not promise returns or present example projections as guaranteed results.
